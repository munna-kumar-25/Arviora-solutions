# Arviora - Modern Service-Based Business Website

A modern, responsive, and feature-rich React.js frontend for a service-based company. The Admin Panel runs as a separate app in the repository's `Admin/` folder.

## Features

### 🎨 Frontend Features
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Modern UI**: Gradient designs, smooth animations with Framer Motion
- **Performance**: Optimized components and lazy loading
- **Accessibility**: WCAG compliant with semantic HTML

### 📄 Main Website Sections
1. **Home Page** - Hero banner, featured services, blog preview, testimonials
2. **About Section** - Company introduction with Mission, Vision, Values
3. **Services Page** - Service cards with pricing and descriptions
4. **Blog Features** - Blog listing with search/filter and detail pages
5. **Testimonials** - Carousel with star ratings
6. **Contact Page** - Contact form, information, map placeholder

The Admin Panel is a separate app; its setup and URL are documented in `../Admin/README.md`.

## Tech Stack

- **React 19** - Latest React version
- **React Router v6** - Client-side routing
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Smooth animations
- **Context API** - State management
- **Axios** - HTTP client for future API integration

## Quick Start

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start development server**
   ```bash
   npm start
   ```

3. **Access the site**
   - Main site: http://localhost:3000
   - Admin panel: follow the setup instructions in `../Admin/README.md`

All of the commands except `eject` will still work, but they will point to the copied scripts so you can tweak them. At this point you're on your own.
